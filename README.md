# 🖱️ Fast Clicker - Hotkey Driven (Key: T)

Una utilidad de automatización sencilla y ligera diseñada para realizar clics repetitivos de forma eficiente. Este proyecto nació como una solución simple para tareas tediosas, permitiendo al usuario controlar la ejecución mediante una tecla de acceso rápido (*hotkey*).

---

## 📖 Descripción del Proyecto

Este proyecto consiste en un script de automatización que emula clics del ratón a alta velocidad. No es una herramienta compleja, pero el foco principal fue lograr una detección de teclado en segundo plano que no interfiriera con otras aplicaciones, permitiendo activar y desactivar la función de clic instantáneamente con solo pulsar la tecla **"T"**.

---

## 🚀 Características Principales

* **Activación por Hotkey**: Inicia y detiene el proceso de clic automáticamente al pulsar la tecla **'T'**.
* **Modo Toggle**: Un solo toque activa el bucle; otro toque lo detiene, evitando la necesidad de mantener presionada la tecla.
* **Multihilo (Threading)**: La lógica de clic se ejecuta en un hilo separado para que el script siempre esté atento a la tecla de apagado, garantizando una respuesta inmediata.
* **Velocidad Ajustable**: Configuración interna para definir el intervalo entre clics (en milisegundos).
